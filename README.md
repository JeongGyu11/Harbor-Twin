# HARBOR TWIN

해운·항만·물류 공모전 시연을 위한 가상 컨테이너선 하역·평형수 조정 웹입니다.

## 실행
VS Code에서 이 폴더를 열고 터미널에서 실행하세요.

    .\start.cmd

또는 Python으로 실행합니다.

    python -m http.server 4174 --bind 127.0.0.1 --directory dist

브라우저에서 http://localhost:4174 에 접속합니다. 수정 후 Ctrl+F5로 새로고침하세요.

## 사용 흐름
1. 3D 선박을 회전하거나 2D 도면에서 화물·탱크 상세를 확인합니다.
2. 하역을 시작하고 추천 운전안을 승인하거나 자동 균형 조정을 켭니다.
3. 하역 100% 후에도 마지막 물 이송이 남아 있으면 일시정지·재개할 수 있습니다.
4. 하역과 조정이 모두 끝나면 '다시 시뮬레이션'으로 새로 시작합니다. 수동 추천이 남으면 승인 후 재생해 마무리합니다.
5. 그래프와 최대 기울기 비교값에서 같은 하역 조건의 무조정 기준과 비교합니다.

## 튜토리얼
필수 기능 14개를 상세히 설명합니다. 실제 화면과 분리된 오른쪽 패널(넓은 화면) 또는 아래 패널(좁은 화면)을 사용합니다. 기능별 바로가기·다음·이전·건너뛰기를 지원합니다. 안내 중 재생이 멈추며 종료 시 원래 보기를 복원합니다. 개정된 가이드는 첫 방문에 다시 표시됩니다.

## 이번 수정
- 마지막 이송 중 일시정지가 초기화하던 문제 수정
- 물 이송 및 최종 상태까지 그래프 기록, 시간에 비례하는 가로축
- 가능한 탱크 조합 전체 비교, 승인 전 재검산, 수위 제한 확인
- 하중 변화로 방향이 부적절해진 이송 재평가
- 적재 높이·물의 높이에 따른 KG, 고정 KM 및 직사각형 탱크 자유표면 보정에 따른 추정 GM
- 계산 범위를 벗어나면 이송 중지, 0도 대신 계산 불가 표시
- 3D 수위와 2D 채움 비율 일치, 3D에서 고른 화물을 2D에서도 강조
- 포인터 취소와 작은 드래그 오인식 보완
- 새 완료 조건·그래프·계산 한계를 튜토리얼에 반영

## 검증
Node.js가 설치된 환경에서 아래 명령을 실행하면 상태·계산 회귀 테스트 17개를 실행합니다.

    node verify.mjs

테스트는 두 하역 시나리오의 완주, 물 총량 보존, 탱크 수위 범위, 마지막 이송의 일시정지·재개, 그래프 최신값, 탱크 대안 선택, 높이 및 수위에 따른 GM 변화, 계산 범위 초과 처리 등을 포함합니다.

## 모델 한계
현재는 규칙 기반 시뮬레이션입니다. 실제 선형·운전 데이터가 없으므로 KM 고정, 선체 무게중심 및 탱크 형상 등은 가정입니다. 화물 높이를 반영한 초기 복원성 근사 모델이지, 실제 선박의 완전한 복원성·구조 강도 검증이 아닙니다. GZ 곡선, 실제 선형에 따른 KM 변화, 파랑·동적 거동, 센서·BWTS·실제 펌프/밸브 연동, 비용·체류 시간·전력 절감 검증은 포함하지 않습니다. '시연 기준 내'는 실제 선박 안전 판정이 아닙니다. 상세 가정은 화면 하단 '모델 및 계산 기준'에서 확인하세요.
